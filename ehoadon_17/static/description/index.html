eHoaDon Integration

Một module tùy chỉnh cho Odoo để quản lý hóa đơn điện tử (eHoaDon) cho các doanh nghiệp Việt Nam.

A custom Odoo module for managing electronic invoices (eHoaDon) for Vietnamese businesses.

Tính năng / Features

  • Tạo và quản lý hóa đơn điện tử / Create and manage e-invoices
  • Gửi hóa đơn tự động / Send invoices automatically
  • Theo dõi trạng thái hóa đơn / Track invoice status
  • Xuất báo cáo hóa đơn / Export invoice reports
  • Tích hợp với Odoo Sales và Accounting / Integrate with Odoo Sales and Accounting

Hỗ trợ Odoo 17. Yêu cầu module Accounting và Vietnam localization.

Supports Odoo 17. Requires the Accounting and Vietnam localization modules.
