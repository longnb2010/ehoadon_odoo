# eHoaDon Odoo

[Vietnamese]
Một module tùy chỉnh cho Odoo để quản lý hóa đơn điện tử (eHoaDon) cho các doanh nghiệp Việt Nam.

[English]
A custom module for Odoo to manage electronic invoices (eHoaDon) for Vietnamese businesses.

---

## 🎯 Tính năng / Features

### 🇻🇳 Tính năng

- ✅ Tạo và quản lý hóa đơn điện tử
- ✅ Gửi hóa đơn tự động
- ✅ Theo dõi trạng thái hóa đơn
- ✅ Xuất báo cáo hóa đơn
- ✅ Tích hợp với Odoo Sales và Accounting

### 🇬🇧 Features

- ✅ Create and manage electronic invoices
- ✅ Auto send invoices
- ✅ Track invoice status
- ✅ Export invoice reports
- ✅ Integration with Odoo Sales and Accounting

## 📦 Phiên bản hỗ trợ / Supported Versions

- **Odoo 13** - Branch: `odoo_13`
- **Odoo 17** - Branch: `17.0`
- **Odoo 17** - Branch: `18.0`
- **Odoo 19** - Branch: `18.0`
- **Odoo 20** - Branch: `20.0`
